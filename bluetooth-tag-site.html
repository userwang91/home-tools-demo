Product Requirements

蓝牙智寻便签

以超薄便签形态切入的 BLE 5.0 物品寻回方案：贴在钥匙、钱包、证件上，手机一键响铃找物，物品也能反过来找手机，并支持家庭协同查找与丢失后的匿名上报。

01

问题与机会

钥匙、钱包、遥控器等高频物品随手放置导致反复寻找，平均每人每天因找物品浪费 5–10 分钟，长期积累造成显著时间损耗与焦虑感。现有蓝牙追踪器（AirTag、Tile 等）体积偏大、价格较高、安装方式单一，难以满足小件物品的轻量化粘贴场景。

蓝牙智寻便签以超薄便签形态切入，结合 BLE 5.0 精准定位与家庭协同查找，填补轻量化、低成本、多场景物品管理的市场空白。

02

目标用户18–55 岁居家人群、上班族、学生及健忘人群

用户类型核心诉求典型场景痛点优先级
居家人群 / 上班族快速找到钥匙、钱包出门前 30 秒内找到物品高
健忘人群 / 老年用户防遗忘提醒、操作简单离家时提醒未带重要物品高
学生群体低成本、轻量化书包、证件、耳机追踪中
家庭多人用户协同查找、权限共享家人帮忙找物品中
母婴 / 宠物用户儿童玩具 / 宠物项圈追踪宠物走失预警低

用户对操作复杂度敏感：期望绑定 ≤ 3 步、查找响应 ≤ 10 秒，并具备家庭多人协同能力。

03

目标与度量指标

核心目标

6 个月内激活 50,000 用户；绑定成功率 100%；查找成功率 ≥ 95%。

体验目标

首次绑定 ≤ 3 分钟；查找延迟 ≤ 2 秒；7 日留存 ≥ 60%。

硬件目标

续航 ≥ 6 个月；室内精度 ≤ 3 米；低电量提醒准确率 ≥ 99%。

商业目标

12 个月家庭共享渗透率 30%；协同定位成功率 ≥ 40%。

04

核心需求与用户故事

R1设备绑定与管理

  • 打开 App 自动扫描附近便签，3 步内完成绑定
  • 自定义名称、图标与分类（如「钥匙」「钱包」）
  • 批量解绑、重置、排序与收藏

R2一键定位查找

  • 点击便签立即蜂鸣 + 灯光闪烁，同步显示距离与方向
  • 地图模式查看最后已知位置，超出蓝牙范围也能追溯
  • 查看历史移动轨迹，回溯最近放置位置

R3双向寻物

  • App 远程触发便签响铃与闪灯
  • 长按便签按键，手机立即响铃并弹通知（静音也生效）

R4防丢与智能提醒

  • 距离超出阈值自动报警
  • 离开家 / 公司时提醒未携带「重要」物品
  • 电量低于 10% 推送通知

R5家庭共享与协同

  • 权限分享给家人，多人同时查找同一物品
  • 标记「丢失」后，其他用户设备匿名辅助定位

R6设置与个性化

  • 蜂鸣音量、LED 开关、提醒距离阈值、静音时段可调
05

功能规格

F1　设备绑定流程 3 步完成，异常可回退

步骤操作系统行为异常处理
1进入「添加设备」自动开启蓝牙扫描，列出附近未绑定便签蓝牙未开启：提示授权
2选择便签，点击「绑定」BLE 配对握手，成功后写入设备 ID失败重试，最多 3 次后引导重置硬件
3命名、选择图标与分类保存至本地与云端，进入主界面网络异常：本地保存，后台同步

F2　查找状态机 待机 / 查找中 / 超出范围 / 已找到 / 低电量

状态触发条件App 行为硬件行为
待机正常连接中显示距离、信号强度低功耗广播
查找中用户点击「查找」显示方向指针，距离 1 秒刷新蜂鸣 + LED 闪烁，30 秒或手动停止
超出范围RSSI 信号丢失 > 5 秒显示最后位置，提示超出范围无响应
已找到点击「停止」或按下便签按键停止查找，记录找到时间停止蜂鸣与闪烁
低电量电量 < 10%推送通知，设备列表标红低频蜂鸣提示

F3　防丢提醒规则 四类提醒均可配置

提醒类型触发条件提醒方式可配置项
离开提醒距离超出阈值（默认 10 米）App 推送 + 震动阈值 5–30 米、开关
遗忘提醒离开常用地点且未携带标记物品App 推送通知重要物品标记、地点设置
低电量提醒电量 < 10%App 推送 + 列表警告图标阈值 5%–20%
静音时段用户设定的免打扰时间段提醒静默（低电量除外）时间段设置

F4　共享权限模型 三级角色

角色权限限制
设备所有者查找、设置、共享、解绑、丢失上报—
家庭成员查找、响铃、查看历史位置不可修改设置、不可解绑、不可再次共享
匿名协助用户丢失模式下匿名上报位置信号不可查看设备信息，数据匿名加密
06

系统架构

采用「硬件 BLE 便签 + 移动端 App + 云端后台」三层架构。App 通过 BLE 5.0 直接与便签通信，实现本地实时定位；云端负责账号管理、设备状态同步、共享权限与丢失协同，位置数据优先本地存储，仅在共享与丢失场景下加密上传。

位置数据本地优先；共享与丢失场景下才经 TLS 加密上传云端，匿名上报不含用户身份信息。

关键假设与待验证项
  • 用户愿为硬件便签支付 29–59 元 / 个，需调研验证。
  • 家庭共享场景中，用户愿意邀请家人注册同一平台账号。
  • 匿名协同网络需 ≥ 10,000 活跃用户才有效，冷启动阶段效果有限。
  • iOS Critical Alert 权限可通过审核，用于静音穿透。
  • 待验证：多墙壁、金属干扰环境下 RSSI 精度能否稳定 ≤ 3 米。
